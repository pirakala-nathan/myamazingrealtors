# Design System — Direction C, "Harbour Navy & Logo Cyan"

**Status:** Approved 2026-11-11. Palette changed 2026-11-18 from noir and champagne gold to navy and the logo's cyan, so the site matches the logo.
**Design canvas:** https://claude.ai/artifact/5XE2nQzjukwJ3Rtb3FKdd8 (Direction C boards and the token sheet)
**Code source of truth:** `web/src/app/globals.css` (`@theme` block)

## Concept

This is a personal-brand site built around **PK Sithamparanathan**, the only Realtor®. The structure is inspired by personal-brand broker sites such as ryanserhant.com:
- the Realtor's name in large type with a large portrait
- a dark results band with big numbers
- a "Watch PK" video section, testimonials, a dated insights list, and a social row

The look, copy and branding are original. Nothing is copied from that site.

## Logo and icons

The official logo was converted to SVG straight from PK's Illustrator files, so these are exact vectors, not traced. `MARs_LogoGlobalColors.ai` (colour), `Logo_Cropped.ai` (white and cyan, for dark backgrounds) and `MARs_LogoNoText.eps` (the mark alone) share the same artwork:
- **Brand teal** `#00B2DB` (R0 G178 B219)
- **Brand grey** `#6E6F72`

| File (in `web/public/brand/`) | Use |
|---|---|
| `logo-horizontal.svg` | Site header (mark beside the wordmark) |
| `logo-horizontal-reverse.svg` | Footer and other dark backgrounds (grey becomes white, as in `Logo_Cropped.ai`) |
| `logo-full.svg` / `logo-full-reverse.svg` | Stacked logo for print, social and email |
| `logo-mark.svg` / `logo-mark-reverse.svg` | The hands-and-roof mark on its own |

Icons are generated by `npm run icons` (`web/scripts/generate-icons.mjs`) from `logo-mark.svg`:
- **Browser tab:** `src/app/favicon.ico` (16, 32 and 48px) and `src/app/icon.svg`. The SVG version turns the windows white in dark browser themes so they stay visible.
- **iPhone/iPad home screen:** `src/app/apple-icon.png` (180px, white background).
- **Android / installed web app:** `public/icons/icon-192.png`, `icon-512.png`, and `icon-maskable-512.png` (the mark sits inside the safe zone for round masks), listed in `src/app/manifest.ts`.

If the logo ever changes, replace `logo-mark.svg` and run `npm run icons` again.

## Colour

The palette is built from the logo. Deep navy carries the dark sections, the way the white-and-cyan logo sits on a dark background, and the logo cyan is the single accent.

| Token | Hex | Use |
|---|---|---|
| `navy-950` | `#06141C` | Footer |
| `navy-900` | `#0A1D28` | Ink, primary buttons, dark sections |
| `navy-800` | `#10293A` | Results band |
| `navy-700` | `#143246` | Inputs on dark |
| `navy-600` / `navy-500` | `#24475E` / `#355A72` | Borders on dark |
| `aqua-400` | `#00B2DB` | The exact logo cyan. Accent on dark, accent buttons (navy text) |
| `aqua-300` | `#5FCFEB` | Hover on dark |
| `aqua-500` | `#0093B8` | Stars, focus ring |
| `aqua-700` | `#00708F` | Accent **text** and links on light backgrounds |
| `mist-100` | `#EEF4F7` | Page background |
| `mist-50` | `#F8FBFC` | Cards |
| `cloud-300` / `cloud-400` | `#D3DEE4` / `#B9C8D0` | Borders and dividers on light |
| `logo-grey` | `#6E6F72` | The logo grey, for decorative details only |
| `body` / `muted` | `#3D4A52` / `#5D5E62` | Body and secondary text |
| `on-dark` / `on-dark-muted` / `on-dark-subtle` | `#EEF4F7` / `#C2D1D9` / `#9FB2BD` | Text on navy |

**Contrast rules:**
- All text pairs meet WCAG AA (4.5:1) or better. For example, `aqua-700` on `mist-100` is 5.1:1, `aqua-400` on `navy-900` is 6.9:1, and `muted` on `mist-100` is 5.8:1.
- Never use `aqua-400` as text on light backgrounds, because it fails contrast (about 2.3:1). Use `aqua-700` there instead.
- White text on a cyan button only passes on `aqua-700`. Use navy text on `aqua-400` buttons.

## Shape and spacing

- **Containers:** max width 1280px, with 16px gutters on phones and 24px on desktop (`container-site` utility).
- **Section padding:** 80–104px vertically on desktop and about 80px on phones.
- **Radius:**
  - 0 for images and cards (editorial look)
  - `rounded-full` for buttons and the mobile action bar
  - inputs are pill-shaped on dark sections
- **Touch targets:** at least 44px. Buttons are `min-h-12`.
